# Search Documentation

Use the search dialog to quickly find content across the TurboPanel documentation.

## How to Search

- **Keyboard shortcut**: Press `Cmd+K` (macOS) or `Ctrl+K` (Windows/Linux) anywhere in the docs
- **Search button**: Click the search icon in the sidebar or header
- **Placeholder**: Type to search across all documentation pages

The search indexes all docs content and returns relevant results as you type, including page titles, headings, and body text.
