# Prerequisites

This page lists what you need on your machine before you follow [Local development](/docs/getting-started/development). Product installation for running TurboPanel in production is covered under [Installation](/docs/getting-started/installation).

## Supported environments

**macOS** and **Linux** are the environments TurboPanel development is written for and routinely tested on.

**Windows** (including **WSL**) is **not officially supported**. Some contributors use WSL successfully, but your mileage may vary; if something fails on Windows, fixups are welcome but the team may not be able to reproduce native Windows issues.

## Required tooling

### Node.js

Node.js **24.x** or newer is required. The instance, UI, and website repos each declare their own `packageManager` field for pnpm.

- **Install:** [nodejs.org](https://nodejs.org/)
- **Verify:** `node --version`

### pnpm

pnpm **11.x** or newer. Using [Corepack](https://nodejs.org/api/corepack.html) is recommended so your pnpm version matches each repo.

- **Install:** `corepack enable`, then use the version each repo requests, or install globally per the [pnpm installation docs](https://pnpm.io/installation)
- **Verify:** `pnpm --version`

### Tilt

[Tilt](https://docs.tilt.dev/) orchestrates the local dev stack from the `dev/` checkout (`tilt up`).

- **macOS:** `brew install tilt-dev/tap/tilt`
- **Linux:** `curl -fsSL https://raw.githubusercontent.com/tilt-dev/tilt/master/scripts/install.sh | bash`
- **Manual:** [Tilt releases](https://github.com/tilt-dev/tilt/releases)
- **Verify:** `tilt version`

### Docker

**Docker** (Docker Engine or Docker Desktop with **Compose** available) is required. Tilt runs Postgres and Caddy in Docker Compose; the daemon installer and production paths also rely on Docker.

- **Install:** [Docker Engine](https://docs.docker.com/engine/install/) or [Docker Desktop](https://docs.docker.com/desktop/)
- **Verify:** `docker version` and `docker compose version`

### openssl

**openssl** is required for TLS certificate generation (`scripts/generate-self-signed-cert.mjs`).

- **macOS:** `brew install openssl` (or use the system LibreSSL — already present)
- **Debian/Ubuntu:** `apt install openssl`
- **Verify:** `openssl version`

## Optional (Deno instance runtime)

Local dev defaults to the **Cloudflare Workers** path (`wrangler dev`). To run the self-hosted Deno instance instead, set `TURBOPANEL_INSTANCE_RUNTIME=deno` in `dev/.env` or use **Switch to Deno Mode** in the Tilt UI nav. Deno mode requires Deno on the host:

| Tool | Purpose | Install |
| ---- | ------- | ------- |
| Deno | Instance runtime | [deno.com](https://docs.deno.com/runtime/getting_started/installation/) |

Co-located dev on a Debian VM (`develop.sh`) uses Deno + systemd and does not use Tilt.

## Next steps

When the above is in place, continue with [Local development](/docs/getting-started/development) for bootstrap, ports, and day-to-day tasks.
