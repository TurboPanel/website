# Signing and the CLA

## Commit Signing

**Outside contributors do not need to sign commits.** No rule on any TurboPanel repository requires signed commits. When a maintainer squash-merges your pull request on GitHub, GitHub creates and signs the merge commit itself, so what lands on `trunk` is signed regardless of how you committed.

Maintainers sign their own commits (SSH signing, set up by the `dev` helper scripts). That is a habit, not a rule you have to follow. If you want to sign yours, GitHub's own guide on signing commits applies as normal.

## The Contributor License Agreement

**You agree to the [Contributor License Agreement](https://github.com/TurboPanel/.github/blob/trunk/CLA.md) by opening a pull request.** There is nothing to sign, no bot and no comment to post.

The pull request template has an **I agree to the Contributor License Agreement** checkbox with a link to the full text. Tick it so the agreement is visible on the pull request. If you contribute for an employer, the agreement says you confirm you have authority to bind them, so check before you open the pull request.

Why it exists: the agreement grants the project the rights it needs to license contributions beyond the public repository license, including under alternative commercial terms. The public licenses of each repository are listed in [Licensing](/docs/getting-started/licensing).
