# Architecture

TurboPanel splits documentation by concern:

- **[Development architecture](/docs/architecture/development-architecture)** — Multi-repo layout, Tilt orchestration, schema sync in dev, ports, and technology choices.
- **[Instance API](/docs/architecture/api)** — Versioned surfaces, routing modules, compose/deploy model with `x-turbopanel` server placement, and how requests flow through the `turbopanel` instance repo.
- **[Daemon cell](/docs/architecture/daemon-cell)** — SQLite-backed Durable Object cell, hibernation, billing model, and Redis parity for self-hosted mode.
- **[Server metrics](/docs/architecture/server-metrics)** — Shared host-metrics contract, Analytics Engine / ClickHouse storage, retention, and the dated Cloudflare cost model.

For deployment and production operations, see [Deployment](/docs/deployment) and [Security](/docs/security/password-safety).
