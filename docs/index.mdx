# Welcome to TurboPanel

TurboPanel is a self-hosted control plane for managing applications and infrastructure. It provides a centralized control surface for Docker management across multiple servers, with flexible deployment options to suit different use cases.

## Deployment Models

| Feature           | Cloud-Hosted               | Self-Hosted                   |
| ----------------- | -------------------------- | ----------------------------- |
| **Pricing**       | Pay per server             | Free, unlimited servers       |
| **Control Plane** | Global Edge Platform       | Docker                        |
| **Communication** | Durable Objects            | HTTPS / WebSocket             |
| **Best For**      | Managed, high availability | Full control and cost savings |

## Key Features

- **Self-hosted**: Run the entire control plane on your own infrastructure
- **Docker-native**: Built for managing Docker containers and services
- **Multi-server**: Manage multiple servers from a single control surface
- **Daemon-based**: Lightweight daemons run on managed servers for remote execution
