# Documentation

TurboPanel gives you one simple place to connect servers, deploy websites and applications, run databases, and handle daily operations.

  **not yet publicly available**. These docs describe the product as we work toward a beta release.
  Join the [waitlist](https://turbopanel.io/sign-up) for TurboPanel High Availability or

</Callout>

## Control plane

TurboPanel High Availability is the planned default when you want TurboPanel to operate the control plane worldwide. Self-hosted delivers the same product on infrastructure you run. **Both paths are in private alpha and not yet publicly available.**

<ControlPlaneOptions />

Details live in the [introduction](/docs/getting-started/introduction). For status and the TurboPanel High Availability waitlist, see [pricing](https://turbopanel.io/pricing).

## Source

Five sibling Git repositories (not a monorepo), bootstrapped by [dev](https://github.com/turbopanel/dev). Local checkouts sit under `$HOME`. How they fit together is in [development architecture](/docs/architecture/development-architecture); bugs go to the [issue tracker](https://github.com/turbopanel/turbopanel/issues).
