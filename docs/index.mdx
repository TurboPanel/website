# Welcome to TurboPanel

TurboPanel is a self-hosted control plane for managing applications and infrastructure. It provides a centralized control surface for Docker management across multiple servers, with flexible deployment options to suit different use cases.

## Deployment Models

| Feature           | Cloud-Hosted               | Self-Hosted                   |
| ----------------- | -------------------------- | ----------------------------- |
| **Pricing**       | Pay per server             | Free, unlimited servers       |
| **Control Plane** | Cloudflare Workers         | Your infrastructure (Deno)  |
| **Communication** | HTTPS / WebSocket          | HTTPS / WebSocket (via Caddy) |
| **Best For**      | Managed, high availability | Full control and cost savings |

## Key Features

- **Self-hosted**: Run the entire control plane on your own infrastructure
- **Docker-native**: Built for managing Docker containers and services
- **Multi-server**: Manage multiple servers from a single control surface
- **Daemon-based**: Lightweight daemons run on managed servers for remote execution

## Repositories

TurboPanel is split across sibling Git repositories (not a monorepo). The [turbopanel-dev](https://github.com/turbopanel/turbopanel-dev) repo bootstraps the rest:

| Repository | Purpose |
| ---------- | ------- |
| [turbopanel-dev](https://github.com/turbopanel/turbopanel-dev) | Dev console (`./console`), bootstrap installer, shared orchestration |
| [turbopanel](https://github.com/turbopanel/turbopanel) | Instance (Hono API — Workers + Deno) |
| [turbopanel-ui](https://github.com/turbopanel/turbopanel-ui) | Expo web / native UI |
| [turbopanel-daemon](https://github.com/turbopanel/turbopanel-daemon) | Remote daemon (Ansible orchestration) |
| [turbopanel-website](https://github.com/turbopanel/turbopanel-website) | Marketing site and these docs |
