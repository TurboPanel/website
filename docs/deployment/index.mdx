# Deployment

Guides for operators who run TurboPanel in production. TurboPanel High Availability and self-hosted control planes are both in **private alpha** and **not yet publicly available** — these pages document planned and preview paths as we work toward a beta release.

<Callout type="info" title="Private alpha">
  Neither TurboPanel High Availability nor self-hosted is publicly available yet. Contributor
  development uses [Vagrant + sibling repos](/docs/getting-started/development); production daemon installs use
  [turbopanel.sh](https://turbopanel.sh) once you have a control plane.
</Callout>

## Typical operator flow

<Steps>
  <Step>
    Choose [self-hosted](/docs/deployment/self-hosted) or TurboPanel High Availability (waitlist at
    [pricing](https://turbopanel.io/pricing)).
  </Step>
  <Step>
    Provision the [control plane](/docs/deployment/control-plane) on your infrastructure or use the
    hosted panel when available.
  </Step>
  <Step>
    Enroll each managed server with [Daemon setup](/docs/deployment/daemon-setup) (`turbopanel.sh` +
    license).
  </Step>
  <Step>
    Harden with [Security](/docs/deployment/security), pair versions via
    [Compatibility](/docs/deployment/compatibility), and plan [upgrades](/docs/deployment/upgrade).
  </Step>
</Steps>
