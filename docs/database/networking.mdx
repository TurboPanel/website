| `created_at` | `timestamp(3) with time zone` | yes | Row creation time. |
| `updated_at` | `timestamp(3) with time zone` | yes | Last write time; the ORM sets it to `now()` on every update. |
| `metadata` | `jsonb` | no | Non-secret descriptors written by the panel; no keys are read by the platform today. |
| `options` | `jsonb` | no | Provider-specific tunnel settings; no keys are read by the platform today. |
| `organization_id` | `uuid` | yes | Parent `organization` row (on delete cascade). |
| `routing_organization_id` | `uuid` | yes | Organization whose servers and sites the tunnel carries; equal to `organization_id` for now, enforced in code only. |
| `carrier_id` | `uuid` | no | Parent `carrier` row (on delete no action). |
| `datacenter_id` | `uuid` | no | Parent `datacenter` row (on delete set null). |
| `secret_id` | `uuid` | no | The sealed run token in `secret`; SET NULL if that row goes, NULL for a provider that needs none. |
| `name` | `text` | yes | Operator name, unique per organization. |
| `status` | `text` | yes | `pending` until created, `active`, `attention` after a provider error, `removing` while being taken down. |
| `provider` | `text` | yes | Tunnel provider, `cloudflare` for now; widened by a forward migration. |
| `external_id` | `text` | no | The provider own tunnel id; NULL until the provider created it. |
| `placement` | `text` | yes | `one` (exactly one `run` portal), `chosen` (the `run` portals) or `all` (every server of the datacenter except the `skip` portals; needs `datacenter_id`). |
