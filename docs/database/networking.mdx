## `bulwark` [#bulwark]

One server's firewall state: its mode, the generation last sent, what the host last answered, and whether the last ruleset was kept.

| Column | Type | Null | Default | Description |
| --- | --- | --- | --- | --- |
| `id` (PK) | `uuid` | no | `uuidv7()` | Primary key (`uuidv7()`, time-ordered). |

| `mode` | `text` | no | `'observe'` | `observe` shows the ruleset and applies nothing (the default), `managed` enforces it and `off` leaves the firewall alone. |
| `generation` | `integer` | no | `0` | Rises by one each time the desired ruleset changes, so a host can tell a stale push from a current one. |
| `last_digest` | `text` | yes |  | The sha256 hex the host last reported for its rendered rulesets; the drift key. |

| `last_applied_at` | `timestamp(3) with time zone` | yes |  | When the host last applied a ruleset; null before the first. |
| `confirmed_at` | `timestamp(3) with time zone` | yes |  | When the last ruleset was confirmed as keeping the host reachable; null before the first. |
