# Database

The control plane keeps its state in one PostgreSQL database (PostgreSQL 18 or newer). There is no browsable table-and-column reference on this site for now.

Every table and every non-obvious column is described inside the database itself, as `COMMENT ON` metadata applied by the migrations. To read the descriptions, connect with `psql` and use `\d+`:

```sh
psql "$TURBOPANEL_DATABASE_URL" -c '\d+ server'
```

`\d+ server` prints the columns of the `server` table with their types and descriptions. `\dt+` lists every table with its summary.

A browsable reference may return after 0.2.x.
