## `backup` [#backup]

One completed managed-engine backup artifact recorded from the daemon's `managed.backup` result; unique per (managed_id, backup_id), cascades with the cluster.

| Column | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `uuid` | yes | Primary key (`uuidv7()`, time-ordered). |
| `created_at` | `timestamp(3) with time zone` | yes | Row creation time. |
| `managed_id` | `uuid` | yes | Parent `managed` row (on delete cascade). |
| `database_id` | `uuid` | no | The `database` row the dump was of, set null if that database is dropped; null for an instance-scope backup. |
| `retention_id` | `uuid` | no | The `retention` whose scheduled run made this artifact; null for a manual backup or once that retention is deleted. |
| `server_id` | `uuid` | no | Host that holds the on-disk artifact (the primary when the backup ran); null after that server is deleted. |
| `origin` | `text` | yes | `backup` when a backup run made the file, `import` when it was brought in to be restored; existing rows are `backup`. |
| `backup_id` | `text` | yes | Daemon-minted `bk_` plus hex token that is also the artifact filename on the host; unique per managed engine, not globally. |
| `size_bytes` | `bigint` | yes | Artifact size in bytes as reported by the daemon after writing the dump; re-checked before a restore. |
| `checksum` | `text` | yes | Lowercase SHA-256 hex digest of the artifact computed by the daemon; a restore refuses on mismatch. |
| `database` | `text` | no | Database name for a single-database backup, kept as history; null for an instance-scope backup. |
| `path` | `text` | yes | Artifact path relative to the backup root of the host that made it (`managed/` plus the cluster id, then the file). |
