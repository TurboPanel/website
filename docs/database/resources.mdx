One config key/value at exactly one scope (organization, workspace, project, environment, service, hosting or server), resolved narrowest-wins into deploy env.

| Column | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `uuid` | yes | Primary key (`uuidv7()`, time-ordered). |
| `created_at` | `timestamp(3) with time zone` | yes | Row creation time. |
| `updated_at` | `timestamp(3) with time zone` | yes | Last write time; the ORM sets it to `now()` on every update. |
| `organization_id` | `uuid` | no | Organization scope parent, the widest inheritance level; exactly one of the seven scope columns is non-null (`variable_exactly_one_parent_check`). |
| `workspace_id` | `uuid` | no | Workspace scope parent, overriding organization values; exactly one of the seven scope columns is non-null, and rows cascade with the parent. |
| `project_id` | `uuid` | no | Project scope parent, overriding workspace values; exactly one of the seven scope columns is non-null, and rows cascade with the parent. |
| `environment_id` | `uuid` | no | Environment scope parent, overriding project values; exactly one of the seven scope columns is non-null, and rows cascade with the parent. |
| `service_id` | `uuid` | no | Service scope parent, overriding environment values; exactly one of the seven scope columns is non-null, and rows cascade with the parent. |
| `hosting_id` | `uuid` | no | Hosting scope parent, the narrowest level, merged per service at deploy (later hosting wins); exactly one of the seven scope columns is non-null. |
| `server_id` | `uuid` | no | Server scope parent, resolved per server at deploy and outside the inheritance chain; exactly one of the seven scope columns is non-null. |
| `binding_id` | `uuid` | no | When set the row is system-owned, materialized by a managed-database binding; client PATCH/DELETE return 403 and the row cascades with the binding. |
| `key` | `varchar(255)` | yes | Environment variable name matching `^[A-Za-z_][A-Za-z0-9_]*$`, unique per scope parent via partial unique indexes. |
| `value` | `text` | yes | Plaintext for non-secrets; for secrets a sealed `tpsecret` envelope (data-encryption key) the API never returns and deploy delivers as a file. |
| `description` | `text` | no | Optional free-text note written by the client API. |
| `is_secret` | `boolean` | yes | True marks the value sealed and write-only: read back as null, never interpolated into YAML or `.env`, compiled to a Compose secret file at deploy. |
| `is_literal` | `boolean` | yes | True escapes `$` so Docker Compose does not interpolate the value; false leaves a `$OTHER` reference for Compose to expand (API field `isLiteral`). |
| `is_for_build` | `boolean` | yes | True injects the non-secret value into `build.args` at deploy (API field `forBuild`); default false. |
| `is_for_runtime` | `boolean` | yes | True injects the non-secret value into the container `environment` at deploy (API field `forRuntime`); default true. |

## `visitor` [#visitor]

One sign-in for a password-protected site: a name and a bcrypt hash the site web server checks, per site service; never returned by a route.

| Column | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `uuid` | yes | Primary key (`uuidv7()`, time-ordered). |
| `created_at` | `timestamp(3) with time zone` | yes | Row creation time. |
| `updated_at` | `timestamp(3) with time zone` | yes | Last write time; the ORM sets it to `now()` on every update. |
| `service_id` | `uuid` | yes | Parent `service` row (on delete cascade). |
| `name` | `text` | yes | User name a visitor types; letters, digits and `._@-`, 1 to 64 characters, unique per site. |
| `password_hash` | `text` | yes | bcrypt hash of the password (`$2a$`, `$2b$` or `$2y$`, cost 10 to 12) written by the control plane; the password itself is never stored. |

## `workspace` [#workspace]

Grouping of projects inside one organization; operator rows are `kind='user'` and each organization also holds exactly one platform `turbopanel` workspace.

| Column | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `uuid` | yes | Primary key (`uuidv7()`, time-ordered). |
| `created_at` | `timestamp(3) with time zone` | yes | Row creation time. |
| `updated_at` | `timestamp(3) with time zone` | yes | Last write time; the ORM sets it to `now()` on every update. |
| `organization_id` | `uuid` | yes | Parent `organization` row (on delete cascade). |
| `name` | `text` | no | Display label under `workspace_name_format_check` (letters, digits, space, `._-`), unique per organization at the API; 'TurboPanel' is reserved from first boot. |
| `kind` | `varchar(32)` | yes | Workspace discriminator: `user` (default, operator-created) or `turbopanel` (the single machine workspace per organization, provisioned at install). |
| `description` | `text` | no | Optional free-text description written by the client API; no format CHECK, app-side length cap only. |
